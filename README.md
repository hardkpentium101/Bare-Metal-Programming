## Getting Started

### Dependencies

* qemu, vncviewer - (used tigerVNC), gdb
* add - add-auto-load-safe-path $(PROJECT_DIR)/.gdbinit    // as trusted source for project level gdbinit, in ~/.config/gdb/gdbinit

### Installing

* install dependencies

### Executing program

* make             // executes make all
* make gdb         // executes qemu, vnc and gdb
